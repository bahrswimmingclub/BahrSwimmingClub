# BahrSwimmingClub — Google-ready website package

## Included
- index.html — responsive website with SEO metadata and structured data
- images/ — optimized BahrSwimmingClub logo and two supplied club photos
- robots.txt — crawler guidance
- sitemap.xml — XML sitemap for Google
- Corrected social handle: @Bahrswimmingclub
- Zanzibar / Mbweni location
- Swimming lessons, competitive training, water safety & lifesaving, open-water swimming, yoga, aqua aerobics and Bahr Adventures
- WhatsApp, phone and email calls-to-action

## Important before launch
1. Upload all three web files to the website root.
2. Confirm the live canonical domain is exactly https://bahrswimmingclub.com/
3. Verify the Instagram and TikTok URLs if the accounts use a different URL slug.
4. Connect Google Search Console and submit https://bahrswimmingclub.com/sitemap.xml
5. Verify the business name, address and contact details in the Google Business Profile.
6. Add real club photos with descriptive filenames and alt text.
7. Do not publish claims about certifications, qualifications, affiliations or facilities unless they are accurate and documented.

## Recommended Google Search Console setup
- Verify domain ownership.
- Submit the sitemap.
- Inspect the homepage URL and request indexing after deployment.
- Monitor indexing, Core Web Vitals and search queries.
